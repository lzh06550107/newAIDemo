## ADR-001 — 首先建立与应用技术栈无关的文档 CI

- 日期：2026-10-12
- 状态：ACTIVE
- 决定：以 Bash 和 Python 3.10+ 标准库实现文档结构、相对链接、状态栏目和验证入口检查，并通过 GitHub-hosted Runner 调用同一入口。
- 原因：产品平台未确定，但仓库文档的完整性可独立验证；避免无依据地选定应用技术栈或制作假应用测试。
- 限制：文档 CI 通过只能证明文档检查完成，**不能**代表应用构建、功能、部署或运行验收通过。
